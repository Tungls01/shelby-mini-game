# Shelby Mini Game 🎮

A browser game that simulates using Shelby Protocol as decentralized storage.

## Features

- Catch falling items game
- Score system
- Game over state
- Upload score (Shelby-style)

## How it works

- Game data is stored via a backend service
- Returns a Shelby-like storage link
- Demonstrates how decentralized storage can be used in games

## Tech Stack

- React (frontend)
- Express (backend)
- Vercel (deployment)
